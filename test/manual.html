Keyboard Language Fix — manual test page

Load the extension unpacked, open this file, then in each box select some text (or leave the caret after a word) and press Ctrl+Shift+Space. Sample input: hgsghl should become السلام.

1. text input

Expect: the selection is replaced, and Ctrl+Z restores it.

2. textarea, multi-line

Expect: only the selected range changes.

3. no selection, caret after a word

Expect: only the word before the caret is converted.

4. contenteditable

Expect: the same behaviour inside a rich-text editor.

hgsghl ugd;l

5. read-only text

Expect: nothing changes here; the result lands on the clipboard.

hgsghl ugd;l

6. reverse direction

Expect: Arabic characters become the English that was meant.

7. inside an iframe

Expect: the frame with the caret converts; the parent stays quiet.

8. number input (must be skipped)

Expect: no change — converting here would blank the field.
