What it does

You typed
hgsghl ugd;l
→
You meant
السلام عليكم
You typed
ghbdtn
→
You meant
привет

It works in both directions and decides which way round from the text itself — you never have to tell it. Ctrl + Z undoes the change like any other edit.

How to use it

  • Select the text in any program — Word, a chat window, a browser, anywhere.
  • Press Ctrl + Shift + Space.
  • That is the whole thing.

Nothing selected? It converts the word you just typed. Text you cannot edit? The corrected version goes to your clipboard instead.

The app has no window. Its icon sits in the notification area beside the clock — double-click it for settings.

Keyboard layouts

Arabic (101) · Persian (Farsi) · Russian (ЙЦУКЕН) · Hebrew · Greek — each in both directions against US QWERTY. Using a layout that differs slightly? Individual keys can be remapped in Settings.

تحميل لويندوز

“Windows says the publisher is unknown”

You will see a blue box the first time you run the installer. Click More info, then Run anyway.

Read what it actually says: SmartScreen could not verify the file because it is not commonly downloaded. That is a statement about popularity, not about the contents — Windows Defender did not find anything in it. Every new program starts this way, and the warning fades as more people install it. It says “unknown publisher” because the file is not signed with a code-signing certificate, which costs a few hundred dollars a year and this tool is free.

You do not have to take that on trust. Instead:

  • Read the source. All of it is public.
  • Watch it being built. The installer is not uploaded from anyone's computer — it is built by GitHub from that source, and the build log is public.
  • Check the file you downloaded. Every release publishes SHA-256 checksums, and a signed provenance record tying the exact bytes to the exact commit. With GitHub CLI:
    gh attestation verify KeyboardLanguageFix-x64-Setup.exe --repo mahmoudiav/Keyboard-Language-Fix
  • Scan it. Upload it to VirusTotal if you would like a second opinion.

The app makes no network connections at all, so there is nothing for it to send anywhere even if you never take our word for it.

Questions

Is it really free?

Yes — free to use and free to share, under the MIT License. There is no paid version, no advertising and no account to create.

Windows shows a blue warning when I run the installer.

Click More info, then Run anyway. The warning means the file is not yet commonly downloaded, not that anything was found in it. The full explanation is above, along with four ways to check the file yourself.

Does it read everything I type?

No, and it could not if it wanted to. It asks Windows for one specific keyboard shortcut, and Windows only ever tells it about that one combination. There is no keyboard hook, no network connection and no telemetry.

Which layouts are supported?

Arabic (101), Persian, Russian (ЙЦУКЕН), Hebrew and Greek, in both directions against US QWERTY. Individual keys can be remapped in Settings if your layout differs, and new layouts are easy to add — write to the address below.

Where does it not work?

In windows running as administrator, such as Task Manager: Windows does not let a normal program send keystrokes to those, and this app never asks for elevation. It also cannot read a selection from the few programs that ignore Ctrl + C.

How do I remove it?

Settings → Apps → Installed apps → Keyboard Language Fix → Uninstall. Your preferences are kept, so reinstalling does not lose your shortcut or layout.

Is there a Mac or Linux version?

Not yet. The browser extension works on any operating system; the desktop app is Windows only for now.
