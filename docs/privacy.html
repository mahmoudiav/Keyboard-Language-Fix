Privacy

Keyboard Language Fix · last updated 26 August 2026

Nothing is collected. Not by the app, and not by this website.

The application

Keyboard Language Fix runs entirely on your own computer. It has no network code in it at all — there is no server for it to talk to, no account to create, and no telemetry, analytics or crash reporting of any kind.

  • Your text never leaves your machine. Converting a selection happens in memory on your computer and is not stored, logged or transmitted.
  • It cannot see what you type. The app registers a single keyboard shortcut with Windows, and Windows only ever notifies it about that one key combination. It is not a keyboard hook and cannot observe other keystrokes.
  • The clipboard is used, briefly. To read your selection the app asks the active program to copy, then puts your previous clipboard contents back. Nothing about it is kept.
  • Your settings stay local. They are one small JSON file in %LOCALAPPDATA%\KeyboardLanguageFix, on your machine only.

The browser extension works the same way. It reads only the text you have selected when you press the shortcut, and it requests no network permissions.

This website

This is a single static page. It sets no cookies, runs no analytics, embeds no trackers, loads nothing from third parties, and has no forms — there is nothing here that could collect anything about you.

The site is hosted on GitHub Pages. Like any web host, GitHub records standard server request data such as IP addresses, for security and abuse prevention. That is GitHub's processing rather than ours, and it is covered by the GitHub Privacy Statement. We have no access to it.

If you write to us

Emailing mahmoudiav@icloud.com naturally shares your address and whatever you write. It is used only to answer you, is never shared or sold, and is not added to any list.

Children

The app is a general-purpose text utility. It collects no information from anyone, of any age.

Changes

If this ever changes, the date at the top changes with it, and the full history of this page is public in the repository. You do not have to take any of the above on trust: the complete source is published, so every claim here can be checked.
